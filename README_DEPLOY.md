# RedevelopAI Ready Site

This is a complete static website for the AI-powered redevelopment intelligence and homebuyer trust platform.

## Files
- index.html — full website
- styles.css — responsive design
- script.js — interactive trust score, project filters, society comparison and chatbot demo
- assets/logo.svg and assets/favicon.svg — logo assets

## Deployment
Upload the full folder to Netlify, Vercel, GitHub Pages, Hostinger, cPanel public_html, or any static host.

## To make it production-ready
- Replace sample developers/projects with actual data.
- Add legal disclaimer, privacy policy and consent wording.
- Connect lead form to Netlify Forms, email, CRM or WhatsApp.
- Add real map integration using Google Maps or Mapbox.
- Add backend/admin dashboard for project uploads.
